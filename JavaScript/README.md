# Решение заданий JavaScript через ООП

Две задачи из документа «Задания Javascript.docx» решены на обычном JavaScript. Каждая задача представлена отдельным классом с приватными полями, проверкой входных данных и публичным методом расчета. Зависимости и сборка не требуются.

## Запуск в Google Chrome

1. Откройте `index.html` в актуальной версии Google Chrome двойным щелчком.
2. Откройте консоль: **F12 → Console** или **Ctrl + Shift + J**.
3. В консоли появятся результаты примеров: **14**, **5**, **7**.

Для своих примеров измените аргументы конструкторов в `main.js` и перезагрузите страницу. Классы также доступны непосредственно в консоли страницы:

```javascript
new CombinationLock(4, "0009", "9990").getMinimumMoves(); // 4
new WorkerTransport(3, "3 3 2").getMinimumCars(); // 3
```

Откройте `tests/index.html`, чтобы запустить проверки в Chrome. Итоги появятся на странице и в консоли. Среди проверок — все 100 пар цифр замка с независимым поиском в ширину и все 1000 сочетаний размеров 1–10 групп с независимым полным перебором рассадок.

## Кодовый замок

Класс `CombinationLock` находится в `src/combination-lock.js`.

```javascript
const lock = new CombinationLock(6, "821906", "797083");
console.log(lock.getMinimumMoves()); // 14
```

Конструктор принимает количество дисков от 1 до 10, текущую и секретную комбинации. Комбинации задаются строками, чтобы сохранять ведущие нули. Их длина должна совпадать с количеством дисков.

Для каждого диска вычисляем разницу `d = Math.abs(current - target)`. Прямой путь занимает `d` действий, путь через переход между 9 и 0 — `10 - d`. Выбираем `Math.min(d, 10 - d)` и суммируем по всем дискам. Одно действие меняет только один диск, поэтому сумма независимых минимумов дает минимальное число действий для всего замка.

В примере расстояния равны `1 + 3 + 4 + 1 + 2 + 3 = 14`.

Время расчета — **O(n)**, дополнительная память — **O(1)**, где `n` — количество дисков.

## Перевозка рабочих

Класс `WorkerTransport` находится в `src/worker-transport.js`.

```javascript
const transport = new WorkerTransport(8, "2 3 4 4 1 2 3 1");
console.log(transport.getMinimumCars()); // 5
```

Конструктор принимает количество групп от 1 до 100 и строку размеров групп от 1 до 4, разделенных пробелами. Дополнительные пробелы и переводы строк допустимы. Количество размеров должно совпадать с количеством групп.

Сначала подсчитываем группы каждого размера, затем распределяем их:

1. Каждая четверка занимает отдельную машину.
2. Каждая тройка занимает отдельную машину; свободное место заполняем одиночной группой, если она есть.
3. Двойки объединяем попарно. Оставшейся двойке выделяем машину и добавляем до двух одиночных групп.
4. Оставшиеся одиночные группы размещаем по четыре в машине.

Четверки и тройки невозможно объединить с другими группами размера больше одного. Две двойки полностью заполняют машину. Если разместить двойки отдельно с одиночными группами, число машин не уменьшится: эти же одиночные группы можно собрать вместе. Поэтому указанный порядок дает минимальное количество машин, сохраняя каждую группу целиком.

Подготовка данных занимает **O(n)** времени и **O(n)** временной памяти из-за разбиения строки. Объект хранит только четыре счетчика групп; сам метод `getMinimumCars()` работает за **O(1)** времени и памяти. Повторный вызов метода не меняет результат и состояние объекта.
